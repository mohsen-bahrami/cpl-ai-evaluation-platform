Conversational AI for Credit for Prior Learning Evaluation

A cloud-deployed platform for testing, benchmarking, and evaluating AI chatbots designed to support structured CPL interviews and evidence gathering.

Open Live Chat

Project Overview

This project was developed as a graduate capstone initiative at Northeastern University. Student teams built and deployed CPL-focused chatbot prototypes, while the instructor platform provided evaluation, benchmarking, diagnostics, and stakeholder-facing review tools.

Multi-Team Evaluation

Compare multiple student-built chatbot systems using standardized CPL scenarios.

Rubric-Based Scoring

Evaluate responses on interview quality, specificity, tone, policy safety, evidence focus, and CPL alignment.

Azure Cloud Deployment

Built with Azure App Service, Azure OpenAI, Azure SQL, Flask, and GitHub Actions CI/CD.

Stakeholder Feedback

Presented to CPL faculty stakeholders for practical feedback and future development direction.

System Architecture

The platform connects deployed student chatbots to an instructor evaluation layer. Standardized scenarios are sent to each chatbot, responses are scored using LLM-assisted rubrics, and results are logged for comparison and analysis.
